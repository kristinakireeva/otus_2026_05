# Парсер логов веб-сервера (`log_parser.py`)

Скрипт предназначен для анализа файлов логов веб-сервера в формате `access.log`. Обработка выполняется построчно за один проход, что позволяет эффективно анализировать файлы большого объема (более 3 млн строк).

## Собираемая статистика
* Общее количество выполненных запросов.
* Количество запросов по основным HTTP-методам (`GET`, `POST`, `PUT`, `DELETE`, `OPTIONS`, `HEAD`).
* Топ-3 IP-адресов с наибольшим количеством запросов.
* Топ-3 самых долгих запросов (метод, URL, IP-адрес, длительность в мс, дата и время).

## Использование

Скрипт принимает один обязательный аргумент — путь к конкретному лог-файлу или к директории с логами.

### 1. Анализ одного файла:
```bash
python3 log_parser.py /путь/к/access.log
```

### 2. Анализ всех лог-файлов в директории:
```bash
python3 log_parser.py /путь/к/папке_с_логами
```

## Результат работы
Для каждого обработанного файла статистика выводится в стандартный поток вывода (терминал) в формате JSON и сохраняется в отдельный файл `<имя_файла>_stats.json` в той же директории.
